# End Shard (Fabric 1.21.11)

Что в моде:
- **Руда обломка Края** - генерируется в Крае (на всех островах), 1 жила до 4 блоков на каждые ~2 чанка, высота 0..80.
  Добывается алмазной кирко́й и лучше. Даёт **Обломок Края** (работает Удача), Шёлковое касание даёт сам блок.
- **Слиток из обломков Края** - переплавка обломка (или руды) в печи / плавильне.
- Инструменты и броня сильнее незеритовых.

| | Незерит | End Shard |
|---|---|---|
| Прочность инструментов | 2031 | 4000 |
| Скорость добычи | 9 | 14 |
| Бонус урона | +4 | +6 |
| Зачаровываемость | 15 | 25 |
| Защита (шлем/нагр./пож./бот.) | 3/8/6/3 | 4/9/7/4 |
| Твёрдость брони | 3 | 4 |
| Сопротивление отбрасыванию (за часть) | 0.1 | 0.15 |

Починка - слитком из обломков Края.
Правка характеристик: `ModToolMaterial.java`, `ModArmorMaterial.java`. Редкость руды: `data/endshard/worldgen/placed_feature/end_shard_ore.json`.
